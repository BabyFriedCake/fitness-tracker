# P011 Voice Coach

状态：进行中

目标：

展示训练语音陪伴能力。

包括：

- 语音状态
- 当前反馈
- 开关设置

## 本地中文 TTS（Sprint 16）

第一版使用设备本地文字转语音能力，在训练页前台播报中文训练反馈。

### 播报来源

- 消费现有、已验证的 `WorkoutVoiceFeedbackEvent`；休息结束的“动作名称，3，2，1，开始”为应用层语音提示，不创建训练事实。
- 可播报训练次数、组完成、动作完成和休息开始反馈；次数使用简短数字播报，例如“1”“2”。
- 不从 UI、模板或识别模块直接构造训练事实。

### 行为边界

- 默认使用中文（`zh-CN`）系统语音。
- 只在当前训练页前台会话中播报；不实现后台持续播放、锁屏控制或通知播报。
- 新反馈可以覆盖尚未结束的旧反馈，避免快速计数时形成过期语音队列。
- Mock 自动计数每 2 秒发送一次既有 `RepCompleted`；休息结束后先完成开始倒计时播报，再开始下一组的 Mock 自动计数。
- 达到目标次数时，先完成最后一次数字播报，再播报本组完成并进入后续休息或完成流程，避免最后一次被后续提示覆盖。
- 用户关闭 Voice Coach 后不得发起播报。
- 播报失败、设备不支持或系统静音不得影响 WorkoutSet 持久化、RestTimer 或 Runtime 状态。

### 非目标

- 不请求麦克风权限。
- 不实现语音识别、语音输入、摄像头、姿态检测或 AI 计数。
- 不保证 iOS 静音模式下仍有声音；此行为由系统 TTS 限制决定。
