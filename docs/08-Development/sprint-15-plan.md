# Sprint 15 Plan

目标：在不破坏已完成 Runtime、History、Exercise Library 基础能力的前提下，继续收敛产品体验和补齐高频缺口。

本 Sprint 关注四类工作：

1. Today 训练卡片按钮颜色与状态感收敛
2. 动作库的视觉收敛、左侧肌群单选与图片导入
3. 模板重量能力的正式建模
4. 设置页的开发环境数据重置
5. Today / 模板动作选择统一为底部上拉选择器
6. 动作图片资源授权与导入策略

## 计划任务

- Today 开始按钮视觉与状态感修正
- 动作库单选筛选、视觉收敛与本地图片导入任务拆分
- 模板重量能力任务拆分
- 设置页开发环境数据重置任务拆分
- 模板/计划动作选择底部上拉选择器任务拆分
- 动作图片资源授权与导入任务拆分

## 风险

- 模板重量会影响 Domain、Schema、Migration、Repository 和编辑页，不应以纯 UI 方式绕过。
- 动作库图片必须受授权和离线可用性约束，不允许直接运行时依赖 GitHub。
- 底部上拉选择器会影响多个入口，需要统一选择结果契约。
