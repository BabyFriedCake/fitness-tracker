# S15-06 Exercise Media License and Import

## 目标

在确认可分发授权的前提下，把 `hasaneyldrm/exercises-dataset` 的动作图片资源导入本地，并保持离线可用。

## 范围

- 确认 `hasaneyldrm/exercises-dataset` 中可使用的图片来源与授权范围
- 建立图片资源导入清单与来源记录
- 导入少量已批准的动作图片到本地资源
- 将动作种子数据的 `imageUri` 绑定到本地资源
- 保留无图片动作的占位图回退

## 不做

- 不在运行时从 GitHub 读取图片
- 不导入未确认授权的媒体
- 不把 GIF 作为 V1 必须项
- 不修改 WorkoutSession 历史事实

## 验收标准

- 每张导入图片都有明确来源与授权记录
- 动作库优先展示本地图片资源
- 图片缺失时仍可离线浏览并显示占位图
- 不存在运行时联网拉图

## 测试要求

- 图片导入清单测试
- seed 资源映射测试
- 动作库图片渲染回归测试
- 授权缺失时占位图回退测试
