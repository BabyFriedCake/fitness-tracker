# S14-04 Exercise Media Asset Strategy

状态：Completed

## 目标

确认动作库图片的正式资源策略，避免把无授权媒体导入正式数据。

## 范围

- 审计当前动作库图片占位策略。
- 评估可合法分发的本地图片来源。
- 设计 Dataset Import 到 Local Repository 的图片字段策略。
- 输出是否进入后续实现任务的建议。

## 非范围

- 不下载或导入未确认授权的第三方图片。
- 不运行时读取 GitHub。
- 不修改 Database Schema / Migration，除非后续任务明确批准。
- 不实现自定义动作图片上传。

## 验收标准

- 图片资源来源、许可、打包方式和替换路径清晰。
- 当前占位图策略是否保留有明确结论。
- 若需要正式导入图片，拆出后续任务并列出文档更新要求。

## 验证要求

- `git status --short`
- `git diff --check`
- 如只做策略文档，不运行完整测试。
