# S8-02 Template Detail and Edit Flow

状态：Done

## 目标

把模板列表、模板详情和模板编辑明确分流，符合当前 Prototype 交互。

## 范围

- 模板列表点击进入详情页
- 详情页右上角提供编辑入口
- 编辑页只负责改模板，不承担详情展示职责

## 不做

- 不改训练历史事实
- 不引入新的模板类型
- 不改 WorkoutSession

## 验收标准

- 模板列表点击卡片进入详情页
- 详情页显示模板内容和进入训练入口
- 编辑入口只在详情页提供

## 测试要求

- 列表 → 详情导航测试
- 详情 → 编辑导航测试
- 详情页渲染测试
